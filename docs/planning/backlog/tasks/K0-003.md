## 缺口

1. Guard 谓词从名称到形式化定义（输入/输出/不变量/拒绝条件）
2. Task 状态集合 {CREATED, READY, RUNNING, ...} 的完整枚举与终态定义
3. Step 状态集合的完整枚举
4. 转换表完整性：每对 (from, to) 要么有合法转换、要么显式禁止
5. 正反例：合法转换通过、非法转换被拒
6. 与 K0-002 DP-1（Guard 11 条 Step 来源）和 DP-5b（FENCED_COMMIT）的依赖关系明确化
