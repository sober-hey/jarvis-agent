## 这些报告的写法

- 每条结论都要带证据（命令与输出、日志行号、测试结果），没有证据的一律标"未验证"。
- 不把 macOS 本地通过写成 Linux 生产通过。
- 失败与未覆盖的部分要留在正文，不能只写成功项。
