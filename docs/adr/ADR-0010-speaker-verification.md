# ADR-0010 声纹用本地 CAM++，默认拦截，参考音必须来自本人真实录音

状态：已实施（2026-10-21）
相关：`packaging/voice_speaker.py`、`~/.jarvis/models/campplus.onnx`

## 背景

Sir 要求 JARVIS 能分清"我在说话"和"别人在说话"：他和别人聊天时应让路，聊完再问一句是否继续。

## 决策

1. 用 sherpa-onnx + 3D-Speaker CAM++（192 维嵌入），模型 27 MB 放本机，不联网。
2. 参考声纹由 Sir 的真实近讲录音计算质心，存 `~/.jarvis/speaker-owner.npy`。
3. 阈值 0.35；最短判定片段 1.0 s（更短的判不了，按"不确定"处理，不拦）。
4. 判为他人：不转写、不回答，进入让路状态；静默 20 秒后播一句追问（系统级台词，非模型生成）。

## 证据（本机实测）

| 样本 | 与参考的余弦相似度 |
|---|---|
| Sir 今天 5 段真实录音 vs 质心 | 0.48 / 0.71 / 0.74 / 0.79 / 0.81 |
| 女声思思（TTS） | 0.04 |
| 旧英文 TTS 样本 | −0.08 |

端到端：Sir 录音 → `speaker_score 0.71 owner=True` 正常回答；女声 → `score=0.03` 判为他人，
无回答，20 秒后 `conversation_ended` 并播出追问。

## 踩过的坑

第一版参考音用的是 10-20 做音色实验的 TTS 样本（内容是英文），导致 Sir 本人被判定为他人
（score −0.10），表现为"问了不回答，只听到一句 Sir"。教训：**参考音必须来自本人的真实录音**，
并且要验证同人分段之间的相似度分布，再定阈值。

## 限制

换房间、压低嗓子、隔远说话可能落在阈值下方；真出现时用 `~/.jarvis/utterances/` 里最近的
真实片段重建参考，而不是直接调低阈值。
