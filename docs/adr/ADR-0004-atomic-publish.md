# ADR-0004：macOS 原子不覆盖发布

- Status: PENDING_VALIDATION
- Engineering Plan: v1.1.1

## 候选决策

候选方案是同文件系统硬链接创建目标。禁止先 exists 再使用覆盖式 os.replace。目标冲突必须 BLOCK，不得覆盖。

## 验证要求

真实外接硬盘文件系统、并发冲突、符号链接、崩溃恢复和同步语义。

## 冻结条件

- 契约与实现一致。
- 真实平台测试通过。
- 必需故障注入通过。
- 记录验证证据。
- 获得必要的人工批准。

当前不代表正式批准。

## 2026-10-18 补证核查（不构成批准）

- 状态保持 `PENDING_VALIDATION`。报告：[本机补证与剩余缺口](../reports/ADR-0004_VALIDATION_20261018T083809+0800/REPORT.md)；机器结果同目录 `results-final.json`。
